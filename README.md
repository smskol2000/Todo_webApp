
Django AJAX To-Do Web App

A lightweight, responsive CRUD To-Do application built with Python Django and asynchronous AJAX (JavaScript). This project demonstrates how to perform seamless, real-time database operations without reloading the webpage, delivering a smooth user experience.

Features

• Create Tasks: Add new to-do items instantly.
• Read Tasks: View a dynamically updated list of tasks.
• Update Tasks: Mark tasks as complete or edit their content on the fly.
• Delete Tasks: Remove tasks with immediate UI updates.
• Asynchronous Operations: Fully powered by AJAX for a seamless, no-reload experience.
• Clean UI: Responsive design styled with [Bootstrap / Custom CSS - Choose one].
